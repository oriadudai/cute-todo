# המשימות שלי 🌸

אפליקציית אנדרואיד קטנה לרשימת משימות, עם ווידג'ט למסך הבית.
כל המידע נשמר רק בטלפון.

## מה יש בה
- הוספת משימה עם אימוג'י (לחיצה על העיגול שמשמאל לשדה מחליפה אימוג'י)
- לחיצה על משימה מסמנת שבוצעה, ולחיצה נוספת מבטלת
- החלקה הצידה מוחקת, ואפשר לבטל דרך ההודעה שקופצת
- "ניקוי משימות שבוצעו" מוחק את כל מה שסומן
- ווידג'ט במסך הבית: רואים את המשימות, מסמנים שבוצעו ישר מהווידג'ט, ו־+ פותח את האפליקציה עם מקלדת מוכנה
- האפליקציה והווידג'ט מתעדכנים זה מזה מיד

## בנייה בענן (בלי Android Studio)
1. פותחים ריפו חדש ב־GitHub (למשל `cute-todo`) ומעלים אליו את כל התיקייה, כולל `.github`.
2. אחרי ה־push רץ אוטומטית Build APK בלשונית **Actions** (בערך 4–6 דקות).
3. בסיום נוצר Release: נכנסים מהטלפון ל־
   `https://github.com/<user>/cute-todo/releases/latest` ומורידים את `cute-todo.apk`.
4. מתקינים (צריך לאשר התקנה ממקור לא ידוע).

הריפו כולל מפתח חתימה קבוע (`app/debug.keystore`), אז כל גרסה חדשה מותקנת מעל הקודמת והמשימות נשמרות.
